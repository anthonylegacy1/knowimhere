# Accessibility Control

## Goal
Turn the existing A+ navigation button into a clear accessibility panel that works throughout the prototype.

## Changes
- Open an accessible modal from the current A+ button without moving or restyling the header.
- Add Standard, Large, and Extra Large text choices.
- Add High Contrast, Simplified View, and Reduce Motion switches with plain-language descriptions.
- Add a Reset to Default action and a clear close action.
- Save all accessibility choices so they stay active while navigating and after refresh.
- Apply the settings across the site: readable scaling, stronger contrast, less decoration, and disabled nonessential motion including carousel auto-rotation.
- Update the existing help-page text-size control to use the same saved preference system.

## Verification
- Test keyboard focus and labels in the modal.
- Confirm each setting changes the visible page and remains active after navigation and refresh.
- Check the panel and affected layouts at desktop and mobile sizes with no page errors.
